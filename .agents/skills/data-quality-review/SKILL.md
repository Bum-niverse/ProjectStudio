# 절차

1. 입력·출력 schema, 출처, 기준 시점과 단위를 확인한다.
2. 병합 key, 유일성, 예상 cardinality와 기준 행 수를 정의한다.
3. 변경 전후 행·열 수, 중복, 결측률, 타입, 값 범위와 분포를 비교한다.
4. 다대다 join, 시간대·날짜 정렬과 단위 불일치를 검사한다.
5. 미래 정보와 target 파생 정보의 leakage를 검사한다.
6. raw 데이터는 수정하지 않고 파생 경로에 결과를 저장한다.
7. seed, 환경, 입력 버전과 출력 경로를 기록한다.

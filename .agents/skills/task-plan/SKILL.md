# 절차

1. 저장소 조사 결과와 요청을 확인한다.
2. 목적, 사용자 시나리오, 요구사항, 영향 파일과 제외 범위를 정의한다.
3. 데이터·API·DB 변경, 보안·성능 영향과 승인 필요 여부를 정리한다.
4. 구현 단계, 검증 방법, 완료 조건과 중단 조건을 작성한다.
5. `.codex/task-plan.md`를 작성하거나 갱신한다.
6. 승인 필수 변경이 있으면 구현하지 말고 사용자에게 보고한다.

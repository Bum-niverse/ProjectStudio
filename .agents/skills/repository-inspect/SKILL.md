# 절차

1. 적용되는 모든 `AGENTS.md`를 확인한다.
2. README, 패키지·빌드 설정, 환경변수 예시와 CI를 확인한다.
3. 구조, 관련 모듈, 기존 테스트와 재사용 가능한 구현을 조사한다.
4. 브랜치와 Git 변경을 확인하되 사용자 변경을 수정하지 않는다.
5. 실행, test, lint, typecheck와 build 명령을 식별한다.
6. 하네스가 초기화돼 있으면 결과와 불확실성을 `.codex/task-log.md`에 기록한다.
7. 이 단계에서는 제품 코드를 수정하지 않는다.

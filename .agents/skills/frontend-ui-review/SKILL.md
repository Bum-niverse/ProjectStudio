# 적용

`../../../docs/agent-guidelines/ui-ux.md` 전체를 읽고 적용한다. 이 문서는 축약 체크리스트가 아니라 제품 맥락, 접근성, 반응형, 디자인 시스템과 실제 브라우저 검수의 공유 기준이다.

# 절차

1. 사용자 목표와 진입·완료·실패 상태를 정의한다.
2. 기존 디자인 시스템과 공통 컴포넌트를 우선한다.
3. loading, empty, success, error와 permission 상태를 검토한다.
4. semantic HTML, 키보드, focus, label, 대비와 reduced motion을 확인한다.
5. mobile과 desktop, 긴 텍스트와 overflow를 검토한다.
6. 가능한 경우 실제 브라우저로 확인하고 미검증 환경을 명시한다.

# 적용

`../../../docs/agent-guidelines/security.md` 전체를 읽고 적용한다. 이 문서는 축약 체크리스트가 아니라 실서비스 보안 감사, 검증과 사고 대응의 공유 기준이다.

# 절차

1. 자산과 신뢰 경계, 공격·오용 경로를 정의한다.
2. 인증, 인가, 소유권, 입력, secret, 오류와 로그를 검토한다.
3. 익명, 권한 부족, 다른 계정, 변조 입력과 반복 요청을 격리 환경에서 검증한다.
4. 운영 데이터나 제3자 시스템을 침해하지 않는다.
5. 코드, 마이그레이션 생성, 운영 적용과 운영 검증을 구분해 보고한다.

# Codex 작업 상태

하네스가 적용된 프로젝트의 비단순 작업은 필요에 따라 다음 파일을 사용한다.

- `task-plan.md`: 목적, 범위, 완료 조건과 검증 계획
- `task-state.json`: 현재 단계와 상태
- `validation-report.json`: 실제 검증 결과
- `task-log.md`: 주요 결정, blocker와 잔여 위험

이 파일에는 비밀정보, 개인정보, 원본 데이터와 대용량 실행 로그를 저장하지 않는다. 기본 `.gitignore`는 작업별 상태 파일을 제외하며, 팀에서 증거를 공유하려면 저장소 정책에 맞게 명시적으로 변경한다.

# ProjectStudio 로컬 데이터와 개인정보

## 저장 방식

ProjectStudio 프로젝트, PRD, 기능명세, 유저플로우와 변경 기록은 사용자의 Windows 앱 데이터 폴더에 있는 `projectstudio.db` SQLite 파일에 저장된다. 설정의 `로컬 데이터와 개인정보`에서 현재 컴퓨터의 정확한 경로를 확인할 수 있다.

- ProjectStudio 서버나 공개 클라우드에 자동 업로드하지 않는다.
- 다른 컴퓨터의 ProjectStudio와 자동 동기화하지 않는다.
- Windows 사용자 계정마다 별도의 데이터 폴더를 사용한다.
- 앱을 업데이트하거나 덮어 설치해도 앱 데이터 폴더는 유지한다.
- 앱 삭제 프로그램이 로컬 데이터까지 자동 삭제한다고 가정하지 않는다. 완전 삭제 전에는 설정에 표시된 데이터 폴더를 별도로 확인한다.

## GitHub 인증

앱 진입은 로컬 GitHub CLI 세션으로 확인한다. ProjectStudio는 GitHub 토큰과 비밀번호를 자체 데이터베이스에 저장하지 않는다. GitHub CLI 인증 정보는 GitHub CLI와 Windows 자격 증명 저장소가 관리한다.

GitHub 로그인은 앱 화면 접근을 제한하지만 SQLite 파일 자체를 암호화하지 않는다. 컴퓨터를 공유한다면 Windows 계정 암호, 디스크 암호화와 화면 잠금을 함께 사용해야 한다.

## 외부 도구 전송

로컬 프리뷰와 일반 문서 편집은 외부 AI로 문서를 보내지 않는다. Codex 같은 외부 CLI 생성 도구를 사용자가 직접 선택해 실행할 때만 해당 화면에 안내된 프로젝트 이름, 선택 문서와 추가 요청이 도구로 전달된다. API 키와 토큰은 ProjectStudio에 입력하거나 저장하지 않는다.

## 백업

중요 프로젝트는 다음 중 하나로 정기 백업한다.

1. 6단계 내보내기에서 CSV, PDF와 Markdown 패키지를 생성한다.
2. 앱을 완전히 종료한 뒤 설정에 표시된 `projectstudio.db` 파일을 안전한 위치에 복사한다.
3. 연결한 Git 저장소의 `.projectstudio` 문서를 private 원격 저장소에 동기화한다.

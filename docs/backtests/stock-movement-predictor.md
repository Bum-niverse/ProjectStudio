# Stock Movement Predictor 백테스트

## 입력

- 프로젝트 유형: 머신러닝
- 세부 유형: 시계열 예측
- 목적: 공개 일별 OHLCV에서 예측 시점 이전 피처만 사용해 다음 거래일 상승·하락을 분류하고 시간 순서 백테스트로 기준 모델과 비교
- 핵심 제약: 미래 정보 누수 금지, 거래비용 반영, 데이터·피처·모델 버전과 seed 기록, 투자 권유 제외

## 최초 결과와 발견 사항

1. ML 전용 6단계와 문제 정의 골격은 생성됐지만 Codex CLI가 없는 환경에서 상세 필드가 비었다.
2. 데이터·타깃 설계가 빈 상태였고 데이터셋이 없는데도 품질 검토가 정상으로 표시됐다.
3. 실험 설계는 ML 스윔레인을 만들었지만 시스템 설계가 일반 React·Rust·SQLite 앱 구조로 생성됐다.

## 수정

- 로컬 규칙 생성기에 문제·목표, 이해관계자, 분석 질문·가설, 예측 계약, 성공 기준과 제약 기본값을 추가했다.
- 시계열 주가 방향 아이디어를 감지해 제안 상태의 시장 원본·피처/타깃 데이터셋, 변수 사전과 시간 관계 계약을 생성한다.
- 실제 데이터 제공자·기간·라이선스는 추정하지 않고 `확인 필요` 경고로 남긴다.
- 시스템 설계에 프로젝트 유형과 세부 유형을 명시적으로 전달해 ML 파이프라인을 생성한다.
- 데이터·ML 노드에는 일반 서비스용 저장소 경고를 중복 적용하지 않고 전용 검토 규칙을 사용한다.

## 재검증 결과

- 문제·목표 정의: 100%, 예측 계약·가설·성공 기준·제약 생성 확인
- 데이터 설계: 2개 데이터셋, 13개 변수, 1개 시간 관계 생성 확인
- 실험 설계: 데이터 준비, 분할·누수, 모델링·평가, 해석·전달 스윔레인 확인
- 시스템 설계: 11개 노드, 11개 연결의 ML 파이프라인 확인
- 실행 계획: 데이터 계약, 시간 분할, 기준 모델, 후보 모델, 재현성 5개 작업 생성 확인
- 내보내기: CSV, PDF, LLM Markdown, 시스템 설계 JSON과 데이터·실험·ML 문서 선택 확인

## 사용자 확인이 필요한 항목

- 실제 시장 데이터 제공자와 라이선스
- 분석 종목·기간과 생존자 편향 처리
- 수정주가와 기업행동 반영 시점
- 거래비용·슬리피지 가정
- 핵심 지표의 합격 임계값

ProjectStudio는 위 값을 임의로 확정하지 않고 실행 전 검토 항목으로 남긴다.

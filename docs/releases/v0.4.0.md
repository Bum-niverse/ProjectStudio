# ProjectStudio 0.4.0 Beta

## 주요 변경

- 로그인 없이 확인하는 Globeat GitHub Pages 공개 데모
- 실제 작업공간의 151개 기능, 110개 유저플로우 노드와 시스템 설계 예제
- 한국어·영어 화면 선택 및 Codex 생성 결과 언어 연동
- 기능명세 문서·트리·마인드맵 접근 경로 명확화
- README 빠른 사용법, Codex 자동 생성 흐름과 보안 경계 보강
- 공개 GitHub Release 배포 절차 전환

## 보안 및 개인정보

공개 데모는 정적 fixture와 브라우저 메모리 저장소만 사용합니다. 로컬 SQLite, Tauri IPC, 파일 시스템, GitHub·Codex CLI와 인증 정보에는 접근하지 않습니다. Fixture에는 로컬 절대 경로, 이메일 주소와 실제 credential 값이 없음을 자동 검사합니다.

Windows 설치 파일은 아직 코드 서명되지 않았습니다. GitHub Release의 SHA-256 체크섬을 확인한 뒤 설치하세요.

# ProjectStudio 0.3.0 Beta

## 주요 변경

- 웹 서비스와 모바일 앱의 PRD·기능명세·가로 스윔레인 유저플로우·C4 시스템 설계 흐름을 정비했다.
- 데이터 분석과 머신러닝에 문제·목표 정의, 데이터/타깃 설계, 분석·실험 파이프라인, 데이터/ML 시스템 설계와 실행 계획 단계를 추가했다.
- 데이터셋, 변수 사전, 조인 관계, 품질 규칙, 누수·N:N 병합 경고와 실행 작업을 Markdown·JSON·CSV·Mermaid·PDF로 내보낼 수 있다.
- 프로젝트별 로컬 Git 저장소를 SQLite에 저장하고 시스템 노드의 코드·테스트 경로와 구현 상태를 검사한다.
- 기능명세 트리, 유저플로우와 시스템 설계의 자동 배치·분기·테마 가독성을 개선했다.
- 한국어 제목·버튼·레이블이 음절 단위로 잘못 줄바꿈되는 문제를 공통 스타일에서 수정했다.

## 설치와 업데이트

- Windows에서는 NSIS 설치 파일을 권장한다. 기존 버전이 설치되어 있다면 ProjectStudio를 종료한 뒤 새 설치 파일을 실행한다.
- 앱 데이터는 설치 폴더 밖의 Windows 앱 데이터 디렉터리에 유지되지만, 베타 업데이트 전 중요 프로젝트를 내보내는 것을 권장한다.
- GitHub 로그인 잠금에는 GitHub CLI 설치와 로그인이 필요하다. Codex·Claude·Antigravity·Ollama는 선택 사항이다.

## 알려진 제한

- 코드 서명 인증서를 적용하지 않아 Windows SmartScreen 경고가 표시될 수 있다.
- 자동 업데이트 서버와 다중 사용자 협업은 지원하지 않는다.
- ProjectStudio는 데이터 분석이나 모델 학습을 직접 실행하지 않고, 실행 가능한 기획 문맥과 추적 정보를 만든다.
